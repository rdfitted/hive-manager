# Wiki index

This is the entry point for a shared wiki. Add a link here whenever you add a page, and keep descriptions short enough to help readers choose a page.

## How to use this starter

- Read [the schema](schema.md) before adding or moving a page.
- Record meaningful maintenance in [the log](log.md).
- Replace the fill-in prompts below with verified guidance for your own organization. Leave unsupported claims out.

## Categories

- [Patterns](patterns/README.md) — recurring situations and responses.
- [Practices](practices/README.md) — repeatable ways of working.
- [Research](research/README.md) — source-backed findings and open questions.
- [Tools](tools/README.md) — usage notes for tools and workflows.
